# Sistema de Recomendaciones en Kotlin

## Descripción
Proyecto desarrollado en Kotlin que implementa un sistema de recomendaciones utilizando programación funcional.

## Requisitos
- Android Studio
- JDK 17 o superior
- Gradle

## Ejecución

1. Clonar el repositorio.
2. Abrir el proyecto en Android Studio.
3. Esperar a que Gradle sincronice las dependencias.
4. Ejecutar la aplicación con el botón **Run**.

## Estructura

- domain
- validation
- normalization
- scoring
- profile
- similarity
- recommendation
- reporting
- infrastructure

## Funcionalidades

- Modelado del dominio.
- Validaciones funcionales.
- Normalización de productos.
- Generación de recomendaciones.
- Perfil de usuario.
- Similitud entre usuarios.
- Reportes.
- Pruebas unitarias.
